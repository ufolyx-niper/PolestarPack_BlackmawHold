# 艾萨拉 · 黑喉要塞与坏帽子（部落）

在 WoW Forever 中启用本包和 Polestar 0.4.3 或更新版本。在 Polestar 指南选择器搜索「黑喉」，打开「艾萨拉 · 黑喉要塞与坏帽子（部落）」。部落全职业可用，47 级起准备，首趟副本建议 55–60 级组五人。位置、箭头与任务自动接交沿用 Polestar 设置。队友各自检查任务日志。

## 从瓦罗莫克出发

想拿坏帽子，到瓦罗莫克找库尔（21.8，52.1）。冬季依次做毛皮、交冬鱿鱼，再接《致命捕捞》。交 5 张苔蹄毛皮，问他当前的渔汛任务。冬季要 10 条「新鲜的冬鱿鱼」。可在拍卖行搜索这个名字，买齐缺的数量，也可到艾萨拉海岸钓。部落玩家记录初级钓鱼 1 点就能看到渔汛；没看到时先查专业。夏季按 NPC 提供及日志行动。交完渔汛且达到 50 级时，在库尔面前再次对话接受《致命捕捞》。即使黑喉主线已推进到科尔萨，仍会在回营时看到这条可选接取提示。接好后，在雷加斯要塞东北行程中组队找海里的精英巨型鲨鱼，取得鲨鱼排，经过瓦罗莫克时交库尔并选「坏帽子」。只跑黑喉可直接略过帽子；已接想稍后做，可保留日志继续主线。库尔和北海岸的顺路栏按路段显示。开启本指南后，只要已开始帽子支线，回到瓦罗莫克会在本地聊天框提示当前缺多少皮或鱼、能交哪一步，或是否该接捕鲨任务。每次回营、重载或任务阶段变化时可提示一次，同一趟背包数量变化不会刷屏。显示沿用 Polestar 的聊天消息设置。

想采根帽，同一营地找杰迪加接信，去雷霆崖找纳拉·蛮鬃换《追根溯源》。莫高雷天望高地还有《黑喉魔法》。可以在第一次回营地时一趟飞行解决，也可留到进本前。第一次经过奥汀克和埃卡尔时分别问狩猎任务和袋子。乌索兰木喉中立后找诺克接双熊。

## 《光复黑喉》

埃卡尔 → 清三种雷加斯萨特 → 乌索兰报到 → 找失踪的斥候 → 取菲达雷德的护符、削减守军、护送囚犯 → 返回科尔萨 → 向拉格罗尔复命 → 费伍德北口求援 → 击败血喉酋长 → 带战旗回艾萨拉插旗反攻 → 乌索兰亲自接《光复黑喉》。进本击败瓦罗克斯·暗蹄并拾取头颅，回乌索兰交付。中途加入指南时沿用角色日志。护送失败时放弃失败记录，等囚犯回笼后重接。

进本沿途采根帽、捡袋子，枯颌取爪、不屈者取牙，血鬃取仪祭图腾。乌索克的图腾在巨兽房门前，乌索尔的图腾在血鬃对面，跳下尾王洞之前拿齐。拾到羽饰护符项链可在背包使用，出本找 Unele。捡到污染的肉可以找食肉鞭笞者换种荚。部落圣骑士若已在提瑞斯法接到提尔圣物匣，可同趟找血鬃。返程依次在乌索兰、埃达拉斯一带、瓦罗莫克和雷霆崖附近交任务。
